生成工作区

登录与连接设置

登录后勾选内容并点击生成即可。应用自动新建会话并发送三条初始化消息，验证成功后隐藏豆包并处理队列；同一次运行内复用连接。异常处理后点击“启动 / 继续后台队列”。

手动连接（仅故障排查）
  1. 在右侧登录并新建普通会话，点击「开始后台校准」。
  2. 依次复制并手动发送连接消息1、2、3；每条都等回答结束，保持同一会话。
  3. 出现「可以测试」后点击「验证后台连接」。这一步无需操作右侧输入框。
  4. 测试通过后保持连接，在下方加入任务，点击「启动 / 继续后台队列」。用完后再断开。

手动校准最多4分钟，连接验证最多60秒。请求模板仅在当前网页内存中使用，关闭或刷新后清除。遇到签名不可复用、登录、验证、额度或结构变化会停止，不自动重试。请不要同时发送其他消息或切换会话。

进阶诊断 · 原协议采集与网页模式

已确认真实对话端点。现在需要确认字段、事件顺序与两轮消息的关联；此步骤不会自动发送任务。

  1. 在右侧完成登录，新建一个普通会话，点击「开始校准」。
  2. 点击「复制连接消息1」，在右侧手动粘贴发送，等待回答结束。
  3. 在同一会话中发送「复制连接消息2」的内容，等待回答结束，再「结束并导出」。






最多 180 秒，只采集已确认的对话接口。保留协议字段名、事件顺序、控制状态、ID 的本次别名和合成测试匹配信息；正文、查询值、请求头值、Cookie 与登录存储不写入诊断文件。队列保持暂停，采集不会点击、发送或重放请求。

网页定位规则与首次标定
在右侧网页目标元素上右键选择标定。重复消息容器请手动将规则改为通用 CSS 选择器。body 和 done 相对于助手回答容器，其他相对于文档。必须标定 input/send/user/answer/body/done/stop/blocker；联网还需 search/searchEnabled。不要把通用页面容器当作回答。
done 应仅在该回答完整生成后出现；blocker 必须覆盖实际登录、验证码、额度异常提示；stop 为生成中的按钮。展开按钮可配置 expand。规则未确认前保持暂停。
