后台对话 · 单次连接测试

已根据两轮真实响应实现消息绑定和完整回答解析。此测试检查当前网页能否自行生成新签名，随后在后台发送一条校准消息；业务队列仍保持暂停。

  1. 在右侧登录并新建普通测试会话，点击「开始后台校准」。
  2. 依次复制并手动发送测试1、测试2、测试3；每条都等回答结束，保持同一会话。
  3. 出现「可以测试」后点击「测试一次后台调用」。这一步无需操作右侧输入框。
  4. 结束后点击「结束并保存报告」。将报告路径发给开发者。

手动校准最多4分钟，后台测试最多60秒。请求模板仅在当前网页内存中使用，关闭或刷新后清除。遇到签名不可复用、登录、验证、额度或结构变化会停止，不自动重试。请不要同时发送其他消息或切换会话。

网页定位规则与首次标定
在右侧网页目标元素上右键选择标定。重复消息容器请手动将规则改为通用 CSS 选择器。body 和 done 相对于助手回答容器，其他相对于文档。必须标定 input/send/user/answer/body/done/stop/blocker；联网还需 search/searchEnabled。不要把通用页面容器当作回答。
done 应仅在该回答完整生成后出现；blocker 必须覆盖实际登录、验证码、额度异常提示；stop 为生成中的按钮。展开按钮可配置 expand。规则未确认前保持暂停。
