# Automated Pages Generator · v0.3.10

Windows Chromium 桌面生成器。使用者手动登录豆包，建立后台连接后生成 Shopify 页面、首页文案、SEO 和尺码表，无需 API Key。

## 安装与打开

完整解压 `Automated-Pages-Generator-0.3.10-win32-x64-experimental.zip`，打开文件夹中的 `Automated-Pages-Generator.exe`。不要单独复制 EXE。无需 DSH 或另装浏览器，当前未代码签名。

本地入口：`build/0.3.10/Automated-Pages-Generator-win32-x64/Automated-Pages-Generator.exe`。

每次启动清空上次任务、流式内容及界面的导出记录，不恢复旧任务；已导出的文件不删除。导出目录设置与本机登录分区继续保留。

## 后台连接

默认全宽工作区，不显示豆包页面。点击右上角“登录 / 显示豆包”并手动登录，之后勾选内容，点击“生成 / 加入后台队列”即可。

应用会自动检查登录和输入框、新建普通会话，依次发送三条初始化消息，每条等待完整响应，再验证一次后台调用。成功后自动隐藏豆包并执行队列，同一次运行内复用连接。校准消息仍会出现在豆包会话中，不需要你复制发送。初始化期间不要手动输入或切换会话。

遇到验证码、登录失效、额度、未适配的网页入口或响应异常会暂停并展示原因，不重发状态不明的请求。手动处理后点击“启动 / 继续后台队列”；重新初始化会新建会话。暂停按钮也会停止初始化后续发送。已经开始生成但连接丢失的业务任务不能自动重发，须核对后取消并重新创建。

程序通过之前用户诊断记录里的输入框 / 侧栏属性及运行时可见标签定位，不使用坐标或猜测私有接口。自动输入和发送由应用代码完成，开发者不控制你的屏幕。当前真实网站上的首次自动初始化仍需用户验收；定位不匹配会停止并提示。手动连接保留在连接设置的故障排查折叠项中。

刷新、退出、导航会使内存连接失效，下次生成重新自动初始化。登录仍由用户操作，Chromium 继续在本机保存登录分区。

## 页面生成

选择“Shopify 页面与目录”，填写参考标题、描述和折扣；邮箱日期选填。点击“生成 / 加入后台队列”：连接就绪时自动启动，未就绪则自动初始化后执行。

生成七页并附加固定 Contact Us。完整回答通过原有业务校验后，导出 Pages / Menus 两张表、八个可见页面。单字段修改可在高级字段选择中选定路径，以当前完整结果 JSON 为基准，保留未选字段。

## 原项目提示词与后台生成

选择“首页 / SEO / 尺码表文案”，使用原项目的12个选项：页首滚动 Title、大屏广告画面提示词、Banner、公告栏、品牌理念、产品卖点、情绪价值、首页 SEO Title/Description、单品通用 SEO Title/Description、尺码表。

- 支持全选、多选及折扣、免运费、产品特色等重点。
- 可补充 SEO 信息，并选择加入源网址；网址作为材料，不代表程序已经读取或联网核实。
- “本地生成并复制提示词”只拼接文本并复制，不联网、不调用豆包。
- “生成 / 加入后台队列”生成选中的内容，不要求先生成整套页面。
- 结果按项目展示，可逐项复制。尺码表复制内容为纯 HTML，无 JS、CSS；没有真实尺码资料时只说明资料缺失，不编造尺寸。
- 校验通过后另行导出 Content 工作表，列为“项目 / 内容”。这是文案整理表，不冒充 Shopify Pages 导入表。
- 在 JSON 编辑框修改结果后保存，可校验并导出新修订。

## 导出目录与任务控制

在结果区域点击“更改导出目录”，选择本机文件夹；设置会记住，后续导出使用该目录。已有文件不会移动。“打开导出目录”打开当前设置。

任务串行处理；暂停阻止后续发送，当前请求保留绑定，不自动重发。取消当前请求会使连接失效，需要重新初始化。校验错误只允许一次格式修复；仍失败不导出。登录、验证码、额度及协议异常暂停，不绕过或无限重试。

后台联网搜索仍未验证，勾选要求联网的任务会在发送前暂停。当前只支持经过验证的普通单文本块对话，未知结构拒绝导出。

## 数据与卸载

用户目录为 `%APPDATA%/automated-pages-generator/`，保存本机配置、当前会话状态和 Chromium 登录分区。每次启动重置任务列表。模板和签名仅留网页内存，不上传 Cookie、密码、用户数据或诊断。

卸载时关闭应用并移除解压目录即可，用户目录和导出文件保留；彻底清除前请自行备份。

### 0.3.4 校准输入修复

校准提示词允许富文本编辑器产生的换行和空白差异，随机标记与其他文字仍须匹配；回答解析绑定实际发出的文本，业务请求继续严格匹配。此修复经过离线测试，真实豆包发送由使用者验证。升级后若输入框保留上次未发送的校准文字，请先手动清空，再点击生成。

实时状态栏固定在工作区顶部，每秒更新当前状态持续时间、接收字符数与距正文更新时间。任务卡片突出异常和生成状态；步骤条不表示预计完成百分比。

### 文案导出与版本更新（0.3.6）

首页 / SEO / 尺码表任务可选择自动导出 XLSX 或仅应用内显示；选择随任务保存，编辑也沿用此设置。仅应用内结果重启后清空，请先复制或点击“将所选文案导出 XLSX”。Shopify 页面任务继续自动导出。

免安装版启动及每 6 小时检查本仓库最新正式 GitHub Release。默认自动下载，可关闭；也可手动检查和下载。仅接受匹配版本的 Windows x64 ZIP，依据 GitHub 资产 SHA256 校验，再解压到用户数据目录 updates 下的独立目录。准备完成后点击“重启使用新版”；所有任务须完成或取消。程序不会自行中断任务。

新版复用同一用户数据目录；旧程序与已有 XLSX 不覆盖。若新版无法启动，可重新打开原 EXE 恢复。切换后使用新版目录里的 EXE，原快捷方式仍指向旧版。未发布正式 Release、缺少兼容包/摘要或网络错误会显示原因，不影响生成。当前尚未代码签名，校验摘要不是独立的发布者签名。首次需手动升级到 0.3.6，早期版本没有更新入口。

更新模块离线校验与打包验证不等同真实升级验证；重启切换与账号复用由使用者验收。

### 0.3.7 自动校验修复

About Us 保持至少3000英文单词，显示实际词数。字数不足、禁用内容、字段类型和JSON错误最多自动修复3轮；可定位时只返回失败字段/文案项目，程序合并保留其余数据，然后重新执行完整校验。缺少事实不得编造；仍失败则不导出，可编辑后保存或显式开启新一轮修复。

升级前关闭旧版；新版启动时将旧版 state.json 中的校验失败任务保存为本机 failed-results.json，工作区仍默认清空。点击“恢复上次失败结果”，选择任务，再点击“自动修复所选失败任务”。本机文件缺失或旧版已经清空的结果无法恢复。更新按钮要求没有未结束任务，因此本次有失败任务时请直接关闭旧版并手动运行新版，不要先取消失败任务。恢复不自动发送；点击修复才调用豆包。

139 项离线回归通过；真实豆包扩写和自动升级仍由使用者测试。

### 0.3.8 网络与读取诊断

更新请求改用 Electron Chromium 网络栈，遵循系统代理配置；若 GitHub 无法直连，请开启可用的系统代理后检查更新。豆包请求失败细分 HTTP 状态、连接失败、流中断和协议校验；失败时自动保存 diagnostics/doubao-read-failure-*.json（不包含正文、Cookie 或签名）。旧版已丢失的错误细节无法追溯恢复，未宣称协议读取根因已修复。禁止自动重发不确定任务。

### 0.3.9 About Us 与网址 SEO

About Us 初次生成及扩写目标均为4000个英文单词，验收仍至少3000；每个HTML单元格仍不超过32767字符。词数仅统计可见英文词，排除标签、注释、脚本样式与纯数字，处理常用HTML实体。HTML标签未闭合、JSON不完整仍拒绝导出，不拼凑缺失正文。单正文修复优先返回HTML并由本地合并，保留其他字段。JSON失败时显示的是最近完整结果词数，已明确标注。

在“网址生成SEO”输入公开网址，点击“读取网址并通过豆包生成SEO”。程序读取该URL公开HTML（不执行网页脚本、不带登录Cookie），将实际网页标题、描述和正文作为参考，使用已登录豆包生成首页SEO Title和Meta Description。默认应用内显示，可选XLSX。Title不超过70字符，Description不超过180字符；生成目标分别50–60及140–160。结果可编辑复制，长度超限自动修复。网页验证、登录、反爬或动态渲染导致读取失败时停止并提示，不编造网页内容。无需API Key；此功能不等同豆包联网搜索。

145项离线回归通过，真实豆包生成由用户测试。

### 0.3.10 网址读取与自动填充

网址连接关闭/重置时仅重试一次公开网页GET，不重发豆包任务。仍失败显示明确网络提示，HTTP拒绝/限流不重试。站点持续断开需要检查网址、网络或系统代理，不能保证所有网站可读取。

豆包SEO结果校验成功后，自动填入下方参考标题、参考内容和网站地址。只应用最新网址任务且只填一次，后续刷新不覆盖手动修改。失败或不完整结果不填入。149项离线测试通过；真实站点和豆包生成由使用者验证。
