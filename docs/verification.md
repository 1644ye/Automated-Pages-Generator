## 本次改造范围

新增用户点击的短时协议采集：用户手动发送测试消息，程序观察请求结构并生成本地脱敏 JSON。最长 120 秒后自动结束保存，也可手动「结束并导出」。不自动点击、发送或重放请求，不导出 Cookie、请求头值、提示词和回答正文。

记录 HTTP 结束、允许的流结束标记和采集限制时分别表达，不把传输结束当成回答完整。后台直连调用尚未实现，也未声明支持某个未经观察的豆包私有接口。旧版 DOM 路径继续保留；未适配规则时队列保持暂停。

`npm test` 全部 42 项通过。覆盖请求筛选与脱敏、SSE/NDJSON 拆包、1,200 帧长流后的结束标记、截断尾帧拒绝、调试器占用与清理、超时、采集与队列恢复并发隔离，以及原字段合并和 XLSX 导出去重。协议测试使用合成事件和 VM，不是真实豆包结果；JavaScript 语法检查通过。

Windows x64 / Electron 43.3.0 的 0.1.3 构建已成功。包内 16 份源码与资源逐字节匹配，清单版本为 0.1.3；未包含用户目录、诊断文件、依赖或测试目录。常见密钥格式检查无命中。原导出模块生成的合成测试 XLSX 再次由 openpyxl 成功打开，Pages 与 Menus 各 8 条数据；这不是豆包生成或 Excel 界面验收。

这些检查不能替代真实账号测试。开发者没有控制屏幕或代发豆包消息。现场协议采集尚需用户按 [manual-test.md](manual-test.md) 的第一部分执行。
