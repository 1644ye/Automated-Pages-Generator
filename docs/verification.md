## 真实阻塞与未通过项目

开发时实际在浏览器打开豆包网址返回 `net::ERR_CONNECTION_CLOSED`，因此没有获得真实豆包 DOM、登录会话或生成结果。没有猜测默认选择器，也没有调用私有接口。程序要求用户先在实际网页标定规则。

以下项目均为 **未验证**：登录持久化、会话交互、联网搜索、长回答提取、真实 title/字段生成、一次自动修复、验证码/额度暂停恢复、批量端到端、Excel UI 打开。跨页面虚拟化片段的自动拼接尚未实现；缺失绑定时不作为成功导出。不能把当前构建称为可无人值守生产使用的成品。
