# v0.2.0 用户验收

开发者不控制屏幕。以下由使用者操作；未完成前保持“待实测”，不能用离线测试替代。

1. 完整解压，运行 EXE，确认 v0.2.0、旧登录与任务仍在。
2. 新建普通会话，开始校准，依次发送三个测试，执行后台测试；通过后保持连接。
3. 输入参考标题、内容、折扣，加入一个整条任务，启动后台队列。观察正文流式展示、任务完成、自动 XLSX 导出。About Us 要满足3000英文单词及单元格上限；若失败记录具体错误，不视为通过。
4. 点击完成任务，把 hero.description 改为手工内容；仅选择 marketing.hero.title 加入队列。完成后核对新 title、未选描述与页面保持不变。对 marketing.seo 重复测试，检查5组 title / description。
5. 加入两个不同输入任务，确认串行发送、导出文件不同；再次继续不能重复发送 / 导出已完成任务。
6. 正在生成时暂停，等待后继续：不能重发当前请求，不能提前发送第二条。取消排队任务不发送；取消当前任务不导出，提示重新校准。
7. 使用提示词要求不合规 JSON 观察校验失败及最多一次格式修复；模型可能仍遵循系统格式，若未触发则该项记未验证。不要靠模拟回答宣称真实失败路径通过。
8. 勾选联网搜索：任务必须在发送前暂停并提示尚未支持，不能声称联网核实。
9. 用 Excel 打开本次生成文件：Pages 有八个页面，Published 为 TRUE；Menus 包含对应目录；列顺序与旧模板一致。营销文案保存在本地任务，不属于 Pages / Menus 导入字段。
10. 保存编辑产生新文件、旧文件不变。重启后未结束任务不得自动发送；失效绑定需人工核对取消。

遇到问题：点击“断开并保存报告”，提供界面错误与报告路径。不要发送密码、Cookie、用户目录。报告不会包含正文，业务校验错误可直接复制界面文字。
