# v0.3.1 用户验收

开发者不控制屏幕、不发送真实豆包消息，以下由使用者操作。

1. 打开 v0.3.1，点击右上角显示豆包并手动登录。不再点击手动校准或复制连接消息。
2. 选择首页 / SEO 文案，只勾选首页 SEO Title，填材料和折扣，点击生成。
3. 观察程序自动创建新会话，逐条发送三条初始化消息并等待回答，再完成后台验证。不要同时输入或切换会话。
4. 验证通过后网页自动隐藏，任务自动生成，校验通过导出到指定目录。
5. 同一次运行再加入第二条任务，应复用连接，不再发三条初始化消息。
6. 初始化过程中点击暂停，应停止后续发送；点击继续明确重新初始化，不能偷偷重复上一条不明状态消息。
7. 未登录时点击生成，应提示人工登录，业务任务保持待处理；完成登录后点击继续，不需要重新加入任务。
8. 如出现验证码、额度或网页入口变更，应暂停并显示原因。若已有诊断报告，提供界面显示路径，不提供 Cookie 或账号密码。
9. 最后测试完整页面长文及 XLSX，确认仍有 Pages / Menus 与八个可见页面；文案任务导出 Content 表。

真实自动初始化与网页隐藏后持续生成尚待本轮验收，离线回归不代表真实通过。
