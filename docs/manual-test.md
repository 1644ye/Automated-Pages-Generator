# v0.3.0 用户验收

开发者不启动窗口或控制屏幕。以下由用户操作，未操作项目不能视为真实通过。

1. 打开 v0.3.0：应是全宽工作区，上次任务和流式内容为空；已有导出文件还在。
2. 点击“更改导出目录”选择测试文件夹；重启后目录应保留，任务列表仍为空。
3. 点击“登录 / 显示豆包”，在连接设置中新建普通会话，开始校准，依次发送三条连接消息，再验证连接。成功后豆包页面自动隐藏；显示 / 隐藏不应刷新页面。
4. 选择“首页 / SEO / 尺码表文案”，先只勾选“首页 SEO Title”。填参考标题、描述、折扣；点击生成。检查后台完成、逐项结果可复制、选定目录自动生成 Content XLSX。
5. 同时勾选 Banner、产品卖点、SEO 描述，选择折扣重点，加入源网址。先本地复制提示词，确认材料及选择正确；再后台生成，输出只能包含所选项目，不声称网址已经核实。
6. 只勾选尺码表，输入真实尺寸资料或故意留空。结果应是纯 HTML、无JS和CSS；缺资料不能编造数值。
7. 选择“Shopify 页面与目录”生成完整任务：在后台隐藏状态等待长文完成，检查 Pages / Menus、八个页面及 Published 为 TRUE。
8. 多任务串行；暂停后继续不能重发当前任务。修改结果保存应导出新文件，不覆盖旧版。退出再启动后列表清空，文件保留。
9. 如连接异常，展开连接设置，断开保存报告并提供路径。不要提供账号密码或 Cookie。

已知限制：每次启动仍需连接初始化；不能仅保留登录状态就跳过校准。隐藏状态下的长文与新文案选项调用仍需本轮实际验证。
